# تجربة الفم المتحرك — تحسين الشكل وتجهيز الحركة

طلب المستخدم تحسين العمل باستخدام مهارات متقدمة، ثم متابعة التنفيذ.
هذه عينة فم جديدة، مختلفة عن تجربة الشرائح المرفوضة. **لم تُعتمد بعد
تشريحًا نهائيًا للطلاب، ولم يكتمل الرأس أو مخارج الحروف.** الدراسات
المرفوضة وقرارات رفضها محفوظة كما هي.

المعاينة المحلية: `/mouth.html`.

## تغييرات الهيئة

- أُعيد بناء اللسان بسطح متصل من ست رقع Quad ملتحمة. منحنى سهمي دوري
  يحدد الشكل؛ لم تُستخدم أقطاب إغلاق الشرائح أو استبدالات ellipse التي
  صنعت الطرف الملحق والثنية في التجربة السابقة. كل الأبعاد والعرض مستنتجة.
- امتد التدرج بين البطن الحر والكتلة الخلفية السفلية. يتغير ارتفاع اتصال
  القاع حول العضو؛ منخفضًا أمامًا وأعلى حول الجذر، بدل الحزام الأفقي.
  أُخذت حافته من 128 نقطة تماس فعلية مع سطح اللسان باستخدام BVH.
- القاع حجم مخاطي مغلق ذو فتحة تشغلها قاعدة اللسان، مع لجام مغلق رقيق
  يصل السطح البطني بالقاع. هذا تقارب تشكيلي، لا إثبات لاتصالات العضلات
  بالعظم اللامي أو الارتفاق الذقني.
- الحنك الصلب والرخو واللهاة مناطق في حجم مستمر، بلا جدار داخلي عند
  الانتقال. الحنك الرخو قابل للرفع؛ الممر الأنفي البلعومي لم يُستكمل.

رأى اجنت المراجعة تحسنًا حقيقيًا في اتصال الطرف والظهر والجوانب وقراءة
اللسان داخل الأسنان، وحدد المركب البطني والقاع أولوية تالية؛ أُجري هذا
التعديل. هذه مراجعة AI هندسية منفصلة، وليست مراجعة طبيب أو مختص مخارج.
لم نعدّ نجاح الهندسة أو الخامات موافقة تشريحية.

## تجهيز الحركة

استُخدمت [مهارة Blender image to 3D](../.agents/skills/blender-image-to-3d/SKILL.md)
المثبتة بترخيص MIT في فصل المصدر عن التسليم، والتصوير المحايد وخبز
الخامات المحمولة. التطبيق الحالي يتضمن:

1. شبكة تحكم B-spline مستقلة بدقة `5 × 14 × 6`، مع تثبيت منطقة اتصال
   القاع. تُخبز النتيجة إلى Morph Targets؛ المتصفح لا يحتاج Lattice في Blender.
2. رفع الطرف والظهر وسحب الجذر بصورة مستقلة. تصحيح هندسي عرضي يحافظ على
   الحجم عند الشدة القصوى لكل من هذه الحركات، بدل تمديد العضو وحده.
   هذا تصحيح شبكي، وليس محاكاة عضلات أو حفظ حجم مضمونًا لكل التركيبات.
3. محور فك فعلي واحد يحرك الأسنان واللثة السفليتين كجسم صلب، بما في ذلك
   الحالات الوسطية. لا تستخدم الأسنان Morph يغير أبعاد القوس أثناء الدوران.
4. مفاتيح تصحيح للحركة المشتركة بين الفك واللسان/اللجام، بوزن حاصل ضرب
   المتحكمين. المصدر يستخدم Drivers، والتسليم يحمل التصحيحات الصريحة.
5. UV وخامات PBR محمولة: Base Color وNormal وRoughness بدقة 1024، مخبوزة
   بأداة المهارة. التباين السطحي توضيحي؛ لم تُنشأ حليمات تشريحية مزعومة.

الأجزاء المصدرة: اللسان، القاع، اللجام، الحنك، صَفّا الأسنان واللثة.
الأسنان واللثة من Z-Anatomy / BodyParts3D؛ جُمعت مكونات اللثة الأصلية
المتصلة بحسب الفك. مراجع الفك والعظم اللامي داخل المصدر ولا تدخل GLB.
حقوق النموذج وإسناده في `NOTICE.md` إلى جوار المصدر وبنسخة تحت `public/models`.

## المراجعة التقنية وحدودها

[technical-review.json](../artifacts/method-evidence/oral-sculpt/technical-review.json)
يقارن GLB الفعلي بعد استيراده إلى مشهد نظيف بالمصدر في 13 حالة: الراحة،
نصف/كامل كل متحكم، تركيب منها، ثم العودة. يشمل كل الأجزاء، لا اللسان فقط.

في العينة المفحوصة، أقصى فرق تصدير مقاس `0 m`. ظل صف الأسنان صلبًا، وبقي
اتصال الجذر بالقاع دون حد الفحص `0.2 mm`. تراجع تغير حجم اللسان من نحو
21% في الفتح التجريبي الأول إلى أقل من 5% في الحالات الحالية؛ تبلغ
الحالة المركبة المفحوصة أقل من 1%. القيم التفصيلية في التقرير، ولا تمنح
اعتمادًا بصريًا أو حيويًا.

تحققت الأداة من إغلاق الأنسجة الأربعة المؤلفة وعدم انقلاب حجم اللسان.
**لم تُستكمل مراجعة كل التقاطعات والتماس مع الأسنان، أو كامل المجال
المركب للمتحكمات، أو صحة وضعيات الحروف.** لا توجد دعوى محاكاة حجم ثابت
بكل الحالات، أو تسجيل لمتبرع واحد، أو اجتياز M2/M3 الكاملين.

## المراجعة في المتصفح

تستخدم الصفحة Renderer واحدًا، ومفاتيح التشوه الفعلية ومحور الفك المستورد.
يُعاد حساب غطاء المقطع من رؤوس السطح المتشوه في كل تغيير، مع الحفاظ على
الفراغات الداخلية. لا يُلصق مقطع الراحة فوق عضو متحرك. التصوير الأصلي
في Blender يقطع نسخًا مؤقتة من الهندسة الفعلية، ويستخدم مادة مقطع صلبة
بلا إسقاط UV السطح الخارجي على القطع.

توجد اختبارات تحليلية لمقطع مكعب، ومقطع ذي فراغ داخلي، ومقطع يتبع Morph
ويعود للراحة. فحص Chromium يشمل هوية GLB، الحركات الخمس، تحديث المقطع،
العودة، السحب للدوران، تبديل الخامة، التشغيل، التخطيط بعرض 390px وخمول
الرسم. هذا ليس قياس أداء هاتف فعلي. الأدلة في `browser/browser-review.json`.

## إعادة الإنتاج

```sh
npm run assets:oral:build
npm run assets:oral:materials
npm run assets:oral:validate
npm run assets:oral:stage
npm run assets:oral:review -- --master oral-unit.untextured.blend --poses --res 800
npm run assets:oral:review -- --materials --labels floor mouth sagittal --res 900
npm run test:unit
npm run build
npm run preview -- --host 127.0.0.1 --port 4174 --strictPort
# في طرفية أخرى، والخادم يعمل:
npm run test:oral
```

المصدر قبل خبز الخامات محفوظ في `oral-unit.untextured.blend`؛ الملف
الرئيسي يحفظ UV والصور المعبأة ونسخة سطح التظليل. يُعاد الخبز من المصدر
قبل الخبز عند التكرار. تظل الشبكة المربوطة ثابتة بعد إنشاء مفاتيح الحركة.
أي تغيير تشريحي جديد يستلزم إعادة بناء القاع والربط والتصدير والفحص.

الخطوات المتبقية: مراجعة تشريحية بشرية، مزيد من النحت المرجعي عند الحاجة،
فحص التماس، ثم تكامل الفم مع الرأس والأنف والبلعوم، ومعايرة الحروف العربية.
