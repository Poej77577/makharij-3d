## ما تغير في الشكل

- أُعيد تشكيل المنحنى السهمي للسان لإظهار النصل الحر والجذر الهابط بصورة
  أوضح، مع تعديل عرض المقدمة واتصال القاع. بقيت شبكة الرقع المتصلة نفسها؛
  لم تُستبدل الأنسجة بأجسام هندسية منفصلة.
- كشف الفحص الجديد اختراقًا للثة السفلية في الحالات الثماني المختبرة من
  نسخة `de49cae`، رغم خلو فحوص الأسنان السابقة. عولج بملاءمة تأليفية
  محلية لسطح اللثة اللساني الفعلي، مع تنعيم الإزاحة واستيفاء اتجاهات
  رؤوس المصدر عند أقرب مثلث. تُخبز التصحيحات في الراحة والنهايات والحركة
  المشتركة؛ ليست محاكاة عضلات أو حل تصادم فوريًا في المتصفح.
- أُزيلت الصفيحة الأمامية المكررة فوق السطح المخاطي الموجود أصلًا في
  شبكة اللثة العلوية. توفر تلك الشبكة السياق المخاطي الأمامي، ولا نسميها
  عظم الحنك الصلب. يمثل `PALATE` الآن النسيج الرخو واللهاة خلفها فقط.
- أُنشئ الجزء الخلفي من نقاط مصدر فعلية مع شريط ارتباط متداخل ضيق.
  أُبقي أول 15٪ من الشبكة ثابتًا عند رفع الحنك. التداخل بين حجمين مغلقين
  لا يعني لحامًا طوبولوجيًا أو اتصالًا سريريًا مقاسًا.
- خُففت زوائد اللثة الخلفية. حُفظت المثلثات ومعرّفات رؤوس المصدر، مع
  تثبيت الرؤوس القريبة من الأسنان. تفاصيل التعديل ومقارنته محفوظة في
  `form-revision/roof-gingiva`، مع الإسناد وترخيص المشاركة بالمثل.

الأسنان نفسها ومحور الفك الصلب وأصل الوجه والشفتين محفوظة. قياسات الأنسجة
المؤلفة وشكلها العرضي وحدود الحركة مستنتجة، وليست تصويرًا لمتبرع واحد.

[مقارنة الخلوّ السابقة والنهائية](../artifacts/method-evidence/oral-sculpt/tissue-contact-review/013445a15e559c3c/baseline-final-comparison.json)
تربط البصمات والتقارير: تقاطعات الأنسجة الممنوعة انخفضت من 8 إلى صفر.
اختبارات القاع واللجام الـ16 تشخيص واجهات منفصل؛ بقاء التقاطع عند
الارتباط لا يستبعد فجوات موضعية أو تداخلًا زائدًا.

يفحص المصدر كذلك حافتي اللجام واتصال الجذر بالقاع. أقصى مسافة سطحية
مختبرة للجام نحو 0.129 مم مع اللسان و0.028 مم مع القاع. في واجهة الحنك،
بقيت 147 نقطة مختبرة داخل/على حجم اللثة المغلق في الحالات الـ16، ولم تتحرك
الحافة الأمامية. المسافة غير الموقعة لسطح نقطة داخل النسيج ليست فجوة
هوائية؛ لذلك نفصل تصنيف الداخل عن قرب السطح. التفاصيل في
[technical-review.json](../artifacts/method-evidence/oral-sculpt/technical-review.json).

تغير حجم اللسان في الحالات المختبرة أقل من 2٪، كتشخيص شبكي فقط. لا توجد
دعوى عدم انضغاط أو محاكاة عضلات، أو حروف عربية جاهزة للتدريس.

أصبح staging يتطلب تقارير المصدر والتصدير والأسنان والأنسجة والتقاطع
الذاتي، بالبصمة الحالية والمجموعات المحددة كاملة. نجاح ذلك يتيح عرض
التجربة للمراجعة ولا يمنح قبولًا تشريحيًا.

## تحسينات الاستخدام

زوايا أمامية وجانبية وتقريب لتفاصيل الفم، مع الحفاظ على وضعية الأعضاء؛
ثلاث سرعات للحركة؛ وحفظ PNG من الهندسة المرسومة فعلًا مع حالة المراجعة
والإسناد والترخيص. ضُبطت الظلال لتحسين قراءة الأعضاء ومعالجة شرائط
التظليل التي كشفتها المعاينة. لا تغير الإضاءة الهندسة أو نتائج الخلوّ.

فحص Chromium يشمل هوية الملفين، الحركات الثماني، العودة، المقاطع الفعلية،
الكاميرات، محتوى صورة التنزيل، السرعات، التخطيط بعرض 390px والخمول.
اختبارات الوحدة الـ19 والبناء نجحت. هذه ليست تجربة أداء هاتف فعلي.

## حدود الشكل المتبقية

يرى وكيل المراجعة تحسن النصل والجذر والسقف ونهايات اللثة، مع بقاء حافة
وتقعر واسع بشكل حدوة تحت النصل. خفّت التعرجات الصغيرة بالتنعيم ولم يختف
هذا الأثر. كما تحتاج علاقة الجذر بالقاع والحنك الخلفي إلى نحت مرجعي
ومراجعة بشرية، ولا توجد بنية بلعومية/أنفية كاملة أو إغلاق لهائي مثبت.
الوجه سياق CG خارجي، وليس رأسًا داخليًا كاملًا أو واقعية تصويرية.

[المراجعة البصرية المستقلة](../artifacts/method-evidence/oral-sculpt/self-contact-review/FINAL_REVIEW.md).
تبقى `accepted=false` و`productionSelected=false`. لا يعتمد هذا التحديث
الدراسات المرفوضة أو يمرر مراحل M2/M3 أو معايرة الحروف.

## إعادة الإنتاج

```sh
npm run assets:oral:build
npm run assets:oral:materials
npm run assets:oral:validate
npm run assets:oral:contacts
npm run assets:oral:tissue-contacts
# مرّر البصمة الفعلية للبناء الجديد؛ لا تعِد استخدام قيمة قديمة:
npm run assets:oral:self-contacts -- --expected-sha256 <current-glb-sha256>
npm run assets:oral:stage
npm run assets:face:build
npm run assets:face:validate
npm run assets:face:contacts
npm run assets:face:stage
npm run build
npm run preview -- --host 127.0.0.1 --port 4174 --strictPort
# في طرفية أخرى:
npm run test:oral
```

الملف القابل للتحرير `oral-unit.blend`؛ والنسخة قبل الخبز
`oral-unit.untextured.blend`. تحفظ `oral-manifest.json` بصمات الشيفرة
والشكل والمصدر والخامات. نسخة `e051` وصور المقارنة محفوظة تحت
`form-revision/before`؛ الدراسات الأقدم ورفضها محفوظة كذلك.
