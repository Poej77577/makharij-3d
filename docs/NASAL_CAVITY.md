# الممر الأنفي من فتحتي الأنف إلى بداية الحلق

طلب المستخدم تجويف الخيشوم كفراغ متصل. يعرض تبويب **الخيشوم** جدارًا
مخاطيًا يحيط بممر فارغ؛ يبدأ من فتحتي الأنف الأصليتين، ويمتد عبر المسارين
الأنفيين إلى البلعوم الأنفي خلف الحنك. هذه إعادة بناء تعليمية تجريبية،
بأبعاد خفية مستنتجة، وليست تصويرًا طبيًا أو اعتمادًا للغنة والحروف.

## المدخلان والفراغ

كانت فتحات الأنف في أصل MakeHuman جيوبًا مغلقة من الداخل. تُفتح أغطيتها
العميقة فقط مع حفظ حافتي الأنف الخارجيتين وUV ومعرّفات المصدر، ثم تُشتق
حلقات الاتصال من الشبكة المنعمة الفعلية. لا يُقطع الرأس كله أو يُحوّل
غلاف الجلد إلى حجم أنسجة قحف.

`nasal-cavity.glb` يحمل الجدار المخاطي الموجب فقط. غلاف الهواء المغلق
`nasal-airspace.analysis.glb` ملف تحليل منفصل، ولا يُرسم كعضو صلب.
المقطع يكشف الفراغ الحقيقي، وخطوط المسار اختيارية وتوضيحية؛ لا تمثل CFD.
النموذج الأنفي ثابت في وضع الراحة، ولا يثبت إغلاق الحنك الرخو أو تغير
مسار الهواء أثناء كل الحروف. بقية البلعوم والحنجرة خارج نطاق هذه الإضافة.

## الفحص

تفحص أداة `tools/qa/nasal_airway.py` هندسة التسليم وهوية الملفين
والوجه الحالي. تتحقق من مسار ذي عرض موجب من كل مدخل حتى المخرج، ومن
عدم وجود جدار يسد المسار أو غطاء يغلق الفتحات. تختبر الأداة كذلك أمثلة
تحليلية لقناة مفتوحة وأخرى مسدودة قبل الاعتماد على النموذج.

التقرير في `artifacts/method-evidence/nasal-cavity/qa/nasal-airway.json`.
الفحص البرمجي لا يمنح قبولًا طبيًا أو يثبت كل التفاصيل التشريحية الداخلية.
الصور والتفاعل في `artifacts/method-evidence/nasal-cavity/browser`.

## إعادة الإنتاج

```sh
npm run assets:face:build
npm run assets:face:validate
npm run assets:face:contacts
npm run assets:face:stage
npm run assets:nasal:build
npm run assets:nasal:validate
npm run assets:nasal:stage
npm run build
npm run preview -- --host 127.0.0.1 --port 4174 --strictPort
# في طرفية أخرى:
npm run test:nasal
npm run test:oral
```

المصدر القابل للتحرير والبيان في
`artifacts/method-evidence/nasal-cavity`؛ حقوق المصدر والتعديلات في
[NOTICE.md](../artifacts/method-evidence/nasal-cavity/NOTICE.md).

## نتيجة التحقق الحالية

الملف الحالي `db86baa8…` اجتاز فحص المسارين والمنافذ الثلاثة. استُخدمت
كبسولات بنصف قطر 0.25 مم عبر 77 مقطعًا لكل مسار. تحقق الفحص كذلك من
اتصال الجدار وإغلاق أنسجته وعدد فتحاته الصحيح، ومن تطابق حلقات المنخرين
مع الوجه. المفاتيح المحلية الأربعة تتبع حركة المداخل في عشر وضعيات
مفحوصة؛ هذا لا يثبت محاكاة التنفس أو الإغلاق اللهائي.
