# التحقق — النسخة الجديدة

تاريخ إعداد الأدوات: 2026-10-30. هذا الملف يصف أدوات الفحص وحالة الدليل؛ لا يمنح اعتمادًا للنموذج أو للمحتوى.

## الأدوات المتاحة فعليًا

- Blender 4.3.2.
- Chromium 154 مع Python Playwright. أمكن إنشاء سياق WebGL2 باستخدام SwiftShader؛ هذا تصيير برمجي على آلة سحابية، وليس اختبار جهاز طالب أو هاتف فعلي.
- ffmpeg وffprobe لفك الفيديو وفحص إطاراته وتوقيته.
- NumPy وSciPy. ثُبتت أدوات الهندسة في `/tmp/makharij-qa-deps`: trimesh 5.2.0، python-fcl 0.7.0.11، pygltflib 1.16.5، rtree 1.4.1.

لتجهيز أدوات الهندسة من جديد، مع إبقاء التحقق من TLS مفعّلًا:

```sh
python -m pip install --target /tmp/makharij-qa-deps trimesh==5.2.0 python-fcl==0.7.0.11 pygltflib==1.16.5 rtree==1.4.1
```

## فحص المصدر والملف النهائي

```sh
PYTHONPATH=/tmp/makharij-qa-deps python scripts/qa/inspect_mesh.py <actual-mesh-file> --out research/qa/source-inspection.json
```

يفحص الملف المكتسب فعليًا دون إصلاح تلقائي: البصمة، الأجزاء، التحويلات العالمية، الحدود والأبعاد بوحدات الملف، الرؤوس غير الصالحة، المثلثات المنعدمة المساحة، الحواف المفتوحة، اتساق الاتجاه وإغلاق السطح. لا ينسب حجمًا مغلقًا إلى سطح مفتوح. يجب إعادة الفحص على GLB النهائي بعد أي ضغط، ثم مقارنة الأجزاء والتحويلات والتشوهات بالمصدر.

الأبعاد وحدها لا تثبت الوحدات أو صحة النسب. وجود حجم ثلاثي الأبعاد أو سطح مغلق لا يثبت تجويفًا صالحًا أو شكلًا تشريحيًا صحيحًا. يلزم فحص بصري من الجانب والأمام والدوران واللقطات المقربة، مع تسجيل الأجزاء الناقصة.

## تقاطع الحركة

```sh
PYTHONPATH=/tmp/makharij-qa-deps python scripts/qa/check_sampled_collisions.py <samples-manifest.json> --out research/qa/collisions.json
```

يحدد ملف المدخلات وحدة متفقًا عليها (`m` أو `cm` أو `mm`)، وأسماء العقد الفعلية للأزواج المفحوصة، وملفات هندسة متشوهة مصدرة من محرك الحركة النهائي عند أزمنة وسطية ونهائية. لا تكفي ملفات الراحة والأهداف وحدها. مخطط المدخلات موضح داخل السكربت.

يستخدم الفحص FCL لتقاطع أسطح المثلثات والمسافة الدنيا. غياب تقاطع السطح لا ينفي احتواء جسم داخل آخر، ولا يغطي الأزمنة بين العينات. ظهور تماس يحتاج تفسيرًا بحسب العضوين؛ لا يصنف كل تماس خطأً، ولا يخفيه بتسامح عددي غير موثق. الفحوص لا تثبت محاكاة عضلية أو صحة تجويدية.

## بوابات لم تنفذ بعد

لم يُسجَّل هنا اجتياز أي أصل تشريحي أو حركة من المشروع الجديد. تنتظر الفحوص هندسة المصدر الفعلية، قرار الترخيص، عقد المحاور والوحدات، وملفات الحركة النهائية.

بعد تثبيت الأصل والحركة يلزم فحص ر، ق، م، ثم ف وع من التطبيق: اختيار الحرف، تغير السطح الحقيقي، استقلال الأجزاء، تسلسل كامل واختبارات وسطية، صور وفيديو قابل لفك الترميز. يجب تشغيل بناء الإنتاج وفحص تزامن العرضين والكاميرات والتبديل والإيقاف والسرعة والخط الزمني والتسميات والتظليل والهواء والروابط والتنزيلات وأخطاء المتصفح.

اختبارات المقاسات المكتبية واللوحية والهاتفية توثق كمقاسات نافذة محاكاة، ويظل الهاتف الحقيقي والأداء على عتاده غير مفحوصين إلى أن يُختبرا فعليًا. لا يستنتج معدل 60 أو 30 إطارًا من SwiftShader.

حالات مستقلة: مفحوص تقنيًا؛ مراجع تشريحيًا؛ مراجع تجويديًا؛ صوت مراجع ومرخص؛ اعتماد كامل. كلها تبقى معلقة حتى يتوفر دليل مناسب لكل حالة.
