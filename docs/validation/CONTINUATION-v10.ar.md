# تحديث النموذج والقطع الحجمي — v10

النموذج المسلّم للمتصفح يستخدم الآن شبكة الشفتين المصقولة نفسها الموجودة في أصل الراحة v10، بدل نسخة v9 السابقة. تحقق النقل من تطابق مواضع وفهارس الأجزاء الاثني عشر الأخرى حرفيًا. وفي الشفتين، أضافت إعادة التقسيم عينات على الحواف دون تغيير الشكل؛ أقصى فرق لفحص السطح في الاتجاهين 3.85 نانومتر، وفرق المساحة 2.15×10⁻¹¹ م². أجريت استعلامات القرب بالملليمتر لتحسين التكييف العددي فقط؛ الملفات والمحاور ما زالت بالمتر.

فُك ملف GLB الجديد بصورة مستقلة: 104 حالات × 12 سطحًا، دون تقاطعات مرصودة. أدنى نسبة مساحة مثلث اللسان 0.278؛ مسافة منطقة الطرف إلى المنطقة اللثوية 0.132912 مم. البصمة `be34ad893194cc3e192618c89d332916eb5f7976f08617917c94da41e252d6cb`. هذه فحوص هندسية محدودة، وليست اعتمادًا علميًا أو برهان سلامة مستمرًا بين كل عينتين.

أضيفت أسطح قطع محسوبة لستة أجزاء مغلقة ومتسقة الاتجاه: اللسان والحنك الرخو والبطانة الأنفية والمحارات الثلاث. لكل جزء عمليتا stencil وسطح قطع يمسح مخزنه منفردًا. تتبع عينات اللسان التشوه الفعلي؛ وإخفاء العضو أو إلغاء المقطع يخفي سطح قطعه. الأجزاء المفتوحة لا تملأ بحدود وهمية. الخطوط الليفية على اللسان رسم توضيحي وليست بيانات عضلية.

## إعادة الفحص

من جذر المشروع، مع Python3.12 والحزم المثبتة في `scripts/qa/requirements.txt`:

```sh
python docs/assets/verify_selected_source.py
python scripts/qa/check_ra_glb.py
npm run build
npm run preview -- --port 4173 --strictPort
# في طرفية أخرى، مع Chromium في /usr/bin/chromium:
python scripts/qa/check_ra_runtime.py
python scripts/qa/check_section_visibility.py
```

البيئة الحالية تحتوي حزم QA الإضافية في `/tmp/makharij-qa-deps`؛ تستخدم الأوامر الهندسية `PYTHONPATH=/tmp/makharij-qa-deps`. المتصفح يعمل بـSwiftShader البرمجي، ولا يثبت أداء هاتف فعلي. النتائج المتجددة تكتب في `research/qa` المتجاهل في Git؛ السكربتات والمصادر وإعداداتها محفوظة.

لإعادة تصدير الراء من أصل الراحة الحالي، بعد التحقق من البصمة المسجلة في ملف المعايرة:

```sh
blender -b -t 4 --python scripts/motion/export_ra_prototype.py -- --fit-dir data/motion/tongue-fit-ra-v10
cp assets/anatomy/makharij-ra-prototype.glb public/models/makharij-ra-prototype.glb
```

لا تعاد وراثة معايرة بعد تغيير أصل آخر دون فحص توافق جديد. `inherit_ra_refinement.py` يوثق المقارنة التي استُخدمت لنقل v9 إلى v10؛ وليس وسيلة لتجاوز فحص البصمة.

## ما زال قيد العمل

تجربة `mim-local-contact-v10` فصلت تصحيحات التماس المحلية عن تشوه الشفتين الأساسي. في 79 حالة مخزنة ووسطية لم ترصد تقاطعات بين الشفتين المركزيتين أو مع الأسنان، وأدنى نسبة مساحة 0.216. قياس الفجوات في 64 مقطعًا عند الذروة تراوح بين 0.042 و0.441 مم؛ السد الكامل غير مثبت. التداخل مع هوامش اللثة المشتقة من القالب موجود في الراحة وفي بعض الحالات، وحركة الحنك الرخو والمسار الأنفي غير مدمجين؛ لم تدخل التجربة العرض باعتبارها ميمًا جاهزة.

المحاولة العريضة للقاف `qaf-surface-active-v10` فشلت في السد العرضي وفي الحنك الرخو. لا تعرض القاف كحركة مكتملة. جميع هذه التصحيحات هندسة تعليمية مؤلفة، وليست محاكاة عضلية أو قياسات سريرية.
