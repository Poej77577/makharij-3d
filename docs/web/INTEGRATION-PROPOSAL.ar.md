# عقد العارض — ينتظر بوابة الأصل

العارض لا يبدأ حتى اعتماد الأصل المستريح من المنسق بعد فحص B وF. لا تستخدم هذه الوثيقة لإثبات جودة هندسة أو نجاح حركة.

## قرار المصدر والإطار

قرار المنسق: أساس Badin المكتسب فعليًا؛ VocalTractLab غير مقبول كتشريح مسلّم بسبب الأشرطة والجدران وحدود تغطية الأسنان والأنف. لا يدمج العارض متبرعين مختلفين.

التحويل المتفق عليه: وحدات المصدر أمتار، `X=.14-nativeX` نحو الأمام، `Y=nativeZ-.1` نحو الأعلى، `Z=nativeY` جانبي. لا تحجيم. يجب تأكيد المعالم النهائية من ملف معايرة B، ولا تعتمد علامات مرسومة بالتخمين.

## الملفات والملكية

- Agent E: src/viewer.ts وsrc/App.tsx وsrc/styles.css وsrc/main.tsx وملفات واجهة أخرى عند الحاجة.
- Agent C: src/motion.ts وبيانات الحركة.
- Agent B: Blender وملفات GLB؛ لا يغير العارض الهندسة المصدر.
- الأصل يُحمل عبر GLTFLoader، ولا يستبدل بمكونات بدائية عند فشل التحميل.

## عقد C وE

المعرّفات المرحلية: ra, qaf, mim, fa, ayn؛ لا تعميم للحركة على سائر الحروف قبل تحقق المجموعة الأساسية.

`sampleMotion(id,tNormalized)` يعيد:

- `weights: Record<string,number>` بأسماء أهداف التشوه مثل `ra_00`… بحسب الإطار الحقيقي المسلم.
- `phase: string` و`oralOpen: boolean` و`nasalOpen: boolean` و`duration: number`.
- الاستيفاء بين عينتين متجاورتين من الدورة الفعلية، لا انتقال خطي طويل بين الراحة والنهاية فقط.
- وقت موحّد واحد يقود العرضين.

مرشح أسماء الأجزاء، ينتظر تأكيد B: TONGUE, UPPER_TEETH, LOWER_TEETH, UPPER_LIP, LOWER_LIP, HARD_PALATE, SOFT_PALATE, PHARYNX, FACE_CONTEXT.

مطلوب قبل التكامل: مسار GLB وإصدار الأصل وأسماء morph targets المشتركة والمعالم/الكاميرات في world meters ودلالة كل متحكم. لا يُعرض معامل فني باعتباره قياسًا بشريًا.

## التخطيط والسلوك

- WebGLRenderer واحد وكاميرا داخلية جانبية كبيرة وكاميرا أمامية أصغر، مع scissor viewports وزر تبادل الأحجام.
- الزمن والمجسم واحد لكلا الكاميرتين. المقطع الجانبي clipping بصري للهندسة الحجمية الفعلية.
- OrbitControls للدوران والتقريب والتحريك واستعادة الكاميرا. تركيز يستهدف المعلم المحدد للحرف.
- التسميات مرتبطة بإحداثيات المعالم، والتظليل مرتبط بالمادة/الجزء أو منطقة تماس موثقة.
- مسار الهواء اختياري؛ يخضع للإغلاق والحنك الرخو، ويوسم توضيحيًا. لا يُختلق تجويف أنفي مفقود.
- أي تحكم غير متاح يغيب أو يوضح تعذره؛ لا أزرار زخرفية.
- RTL للواجهة، وتفسير مباشر لأدوات الكاميرا.
- حالات فشل تحميل الأصل واضحة، ولا تعويض بمشهد بديل يوهم النجاح.

## التحقق قبل التسليم

يفحص Agent F build الإنتاج، التحميل، التشوه الفعلي، تزامن العرضين وتبادلهما، الأدوات، الاستجابة، وأخطاء المتصفح. تسجيل الفيديو إن نُفذ يجب أن يتضمن دورة فعلية كاملة. اختبار viewport الهاتف لا يدعي اختبار جهاز مادي. لا توجد أداة Sites في الأدوات الحالية؛ لا يفترض أي نشر.

## ضغط أهداف التشوه المتطابقة

C وB اتفقا على أن `data/motion/manifest.json` يتضمن `keyAliases`: المفتاح قد يشير إلى اسم حالة هندسية مشتركة، أو `null` للراحة. العارض يستدعي `resolveGeometryWeights(sampleMotion(id,t).weights, manifest.keyAliases)` قبل تطبيق الأوزان على GLB، ويمسح الأوزان السابقة. الهدف الغائب لأجزاء ثابتة ليس خطأ بذاته؛ غياب جميع الأهداف المطلوبة أو تعارض المفاتيح عن الأصل المسلم خطأ تحميل/عقد، ولا يولّد العارض تشوهًا بديلًا. الزمن يبقى استيفاء عينات متجاورة وفق C.
