# عارض فحص الأصل — ليس منصة تعليمية مكتملة

الواجهة تعرض التنبيه: «عارض فحص أصل — بوابة التشريح لم تجتز بعد». لا أزرار لحروف أو تحريك أو صوت قبل إثبات الأصل والتماس. عند فشل GLB أو غياب الأجزاء المطلوبة، يظهر خطأ ولا ينشأ تشريح بديل.

## الملفات وإعادة التشغيل

- src/viewer.ts: عارض WebGLRenderer واحد، عرض جانبي كبير مع قطع حقيقي عبر Z=0، وعرض أمامي صغير. التبديل يحافظ على نفس الهندسة.
- src/main.ts وsrc/styles.css وindex.html: أدوات الفحص العربية فقط.
- public/models/makharij-rest.glb: نسخة B المستقرة v3؛ SHA256: `409be3fc8d5c34b2327ad4579a4409b20a984f7d80ae3093db4fd386fb0e36b9`. تظل النسخة المصدر في assets/anatomy/makharij-rest.glb تحت ملكية B؛ اختلاف إصدارها لاحقًا لا يغير النسخة المعروضة تلقائيًا.

```sh
cd /workspace/makharij-3d
npm run build
npm run preview -- --port 4173
```

build يفحص TypeScript وينتج dist. البناء اختُبر، مع تحذير حجم حزمة JS نحو 606KB قبل gzip؛ ليس فشل بناء. لا توجد أداة Sites أو عملية نشر مثبتة.

## أدوات الفحص المنفذة

- دوران وتقريب وتحريك مستقل لكل كاميرا، واستعادة وتبادل العرضين.
- المقطع الجانبي يزيل النصف القريب من السطح بالمستوى Z=0؛ لا يسطّح المجسم ولا يستبدله بصورة.
- أمامي افتراضي يضبط الإطار من حدود الشفتين والتيجان؛ مربع «إطار أمامي كامل» يعيد حدود جميع الأجزاء ويكشف جذور/حواف المصدر. يمكن تدوير العرض لكشف حجم الأعضاء.
- تسميات عند مراكز حدود meshes الفعلية، وموسومة بأنها أسماء أجزاء، وليست معالم تماس أو قياسات بشرية.
- اختيار جزء للتركيز أو التظليل، وإظهار/إخفاء سياق الوجه والبطانة الأنفية المؤلفة، وملء الشاشة.
- البطانة الأنفية مؤلفة غير مقاسة، ومواءمة الحنك الرخو تحتاج مراجعة؛ لا يوجد CFD أو صوت.

## تحقق E الجاري

تحت Chromium154 وSwiftShader في هذه الآلة: حُمّل GLB الفعلي ذو12جزءًا و71873مثلثًا، بلا أخطاء JS. تغيرت صورة canvas عند تبديل الكاميرتين، وظهرت11تسمية عند تفعيلها. اختبار viewport390px بلا overflowأفقي؛ ليس اختبار جهاز هاتف فعلي.

أول قياس بعد100ms لم ير إعادة رسم؛ تشخيص الانتظار البرمجي أظهر التغيير بعد وقت كافٍ. رصد F أيضًا تحقق قطع فاشلًا بعد1.5s؛ إعادة فحص E للبناء نفسه عند3s أظهرت فرقًا مرئيًا في clipped.png/unclipped.png. تغيرت الواجهة بعد ذلك لتصيير فوري عند كل أداة، مع data-render-frame/data-clipping/data-swapped على canvas لتنسيق انتظار الاختبارات. لا يُستبدل تقرير F باختبار E؛ إعادة فحص F مطلوبة للبناء المعدل.

الأدلة المحلية: research/web-inspector/*.png وresults.json، مجلد متجاهل في Git. هذه أدلة تشغيل لا مراجعة تشريحية ولا اجتياز بوابة الراحة.

## تجهيز لاحق بلا تفعيل

توجد دوال availableMorphTargets/validateMorphTargets/applyMotionWeights لتطبيق أهداف حقيقية مستقبلًا. تتحقق من اتحاد أسماء الأهداف في المشهد كله، ثم تمسح الأوزان السابقة وتطبق الموجودة لكل mesh. الأجزاء الثابتة لا تتطلب هدفًا؛ أي هدف مطلوب غير موجود في كامل الأصل يُرفض. لا توجد أزرار أو بيانات نشطة تستخدم هذه الدوال قبل تسليم rig حقيقي واجتياز البوابة.

## إعادة فحص F للبناء النهائي

أكمل F فحص بناء inset النهائي الفعلي (`index-Coqzx39e.js`)؛ نجح13فحصًا في تقرير `research/qa/inspector-v3-final-inset/results.json` مع بصمة الحزمة والأصل المستجابين. يشمل ذلك فرق صور القطع الحقيقي بعد انتظار حالة إطار مؤكدة، والكاميرات والأدوات والتسميات والاستجابة. النسخة GLB المعروضة تبقىv3بالبصمة أعلاه. تظل هذه نتيجة عارض تقني، ولا تمنح بوابة تشريح أو حركة أو صوت أو منصة طالب.
