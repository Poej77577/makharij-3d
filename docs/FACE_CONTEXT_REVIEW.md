## المصدر والتنفيذ

- مستودع MakeHuman الأصلي، commit
  `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`. أُبقيت UV الأصلية ومعرّفات
  رؤوس الشبكة منخفضة الكثافة داخل `SOURCE_HEAD/source_vertex_id`.
- الشفتان جزء من جلد الوجه؛ حافتهما الأصلية تضم 38 رأسًا. الجيب الفموي
  العام المرفق بالمصدر، 398 وجهًا، محفوظ مرجعًا مخفيًا ولم يدخل التسليم.
  لم يُضغط أو يُعاد تقديمه كتشريح مخارج.
- أُضيفت مفاتيح المصدر الأصلية لضغط الشفتين وضمهما وبروزهما، مع فتح
  الفم. طُبقت subdivision ثابتة واحدة على جميع الأشكال قبل التصدير.
- يحرك `SPEECH_CONTROLS` في مشهد Blender الموحد المتحكمات الثمانية.
  قيمة `JAW_OPEN` نفسها تحرك جلد الذقن/الشفتين بمفتاح المصدر، والأسنان
  واللثة السفليتين بمحور صلب واحد. لا يُدوّر الجلد مرة ثانية حول المحور.
- العينان من شبكة وربط وخامة المصدر الأصلية، مع قناة Alpha للقرنية.
  تدرج لون الشفتين متصل عبر سطح الشبكة ومصدّر كألوان رؤوس.
- المواءمة إزاحة واحدة من مرجع القاطع العلوي بالمصدر. هذه مواءمة تأليفية
  بين أصلين، وليست تسجيلًا سريريًا. معاملات المفاتيح في
  `data/anatomy/face-context.json` إعدادات تجريبية غير معايرة لحروف العربية.

GLB الوجه يحمل `HEAD_EXTERNAL` و`FACE_EYES` فقط. المشهد الأصلي يحتفظ أيضًا
بمرجع الفم المتحرك. سطح الرأس **مفتوح** عند حدود الفم والعينين والرقبة؛
لا يمثل حجم أنسجة القحف. لذلك يُخفى في طرق عرض الداخل ويُستبعد تمامًا
من أغطية المقاطع. لا يُستبدل به رأس تشريحي داخلي متكامل.

## حدود المراجعة والخطوة التالية

رأى وكيل مراجعة الطريقة أن الوجه يمنح الفم سياقًا بشريًا أوضح، لكنه
لم يقبل الداخل: شكل اللسان/الجذر عام، انتقاله إلى القاع غير واضح، والحنك
الخلفي ونهايات اللثة يحتاجان نحتًا مرجعيًا. هذا حكم مراجعة AI بصري محدود،
وليس رأي طبيب. الوجه نفسه نموذج CG توضيحي، ولا ندّعي واقعية تصويرية.

الأولوية التالية تأهيل نحت داخلي مقنع بهذه العلاقات، ثم مراجعته منفردًا
وفي سياقه قبل التفاصيل الإضافية ومعايرة الحروف. لا تُضاف حروف على أساس
هذه النتائج وحدها، ولا يُعاد اعتماد الأطلس أو تجربة الشرائح المرفوضين.

## إعادة الإنتاج

بعد بناء الفم وخبز خاماته وفحصه وstaging وفق `ORAL_SCULPT_REVIEW.md`:

```sh
npm run assets:face:build
npm run assets:face:validate
npm run assets:face:contacts
npm run assets:face:stage
npm run assets:face:review -- --res 900
npm run build
npm run preview -- --host 127.0.0.1 --port 4174 --strictPort
# في طرفية أخرى:
npm run test:oral
```

التصوير يستخدم [مهارة Blender المثبتة](../.agents/skills/blender-image-to-3d/SKILL.md)
بترخيص MIT، ويسجل بصمات المصدر والأصلين والصور. لا تُشغّل سكربتات
مضمّنة في ملفات Blender. الإسناد والحقوق والتعديلات في
[NOTICE.md](../artifacts/method-evidence/face-context/NOTICE.md).
