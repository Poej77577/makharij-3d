# سجل قرارات المنسق

هذه إعادة تنفيذ من الصفر وفق REQUIREMENTS.ar.md. لم تُستخدم ملفات التطبيق التخطيطي المحذوف.

## الملكية والبوابات

- A: assets/candidates وdocs/assets — اكتساب الأصل وترخيصه وفحص الملف.
- B: scripts/anatomy وassets/anatomy وdocs/anatomy — هندسة الراحة وBlender؛ المالك الوحيد للملف الثنائي.
- C: scripts/motion وdata/motion وsrc/motion.ts — التحريك والمعايرة والعقد؛ لا يكتب Blender بالتزامن مع B.
- D: docs/content وdata/content-review.json — التجويد والصوت والمصادر.
- E: src عدا motion.ts وdocs/web — الواجهة والعارض بعد بوابة الأصل.
- F: scripts/qa وdocs/validation وresearch/qa — تحقق هندسي ومتصفح مستقل عن منفذ الأصل.
- المنسق: هذا السجل، المتطلبات، إعداد المشروع، README، الدمج والحزم والنشر إن أمكن.

لا واجهة قبل فحص أصل حقيقي. لا اعتماد علمي بالاختبار الآلي. غياب خدمة النشر لا يثبت وجود موقع أو رابط.

## إطار مبدئي للفحص فقط

VocalTractLab مرشح فعلي مكتسب وليس اختيارًا مقبولًا نهائيًا: سنتيمتر في المصدر، X أمامي موجب، Y علوي موجب، Z جانبي. إن اختير، يصدر GLB بالمتر بتحويل موحد 0.01 مع توثيق صريح. لا دمج متبرعين بلا معايرة معلنة وبواقي وحدود.

## اختيار أساس التحضير بعد فحص الصور والملفات

اختيرت مجموعة Badin/ArtiSynth لتحضير الهندسة؛ رُفض VTL كما صُدّر بسبب أسنان القوس المبسطة وشرائط الشفاه وقصور التجاويف. الصور الخام المقروءة أظهرت لسان Badin الممتد وجذره وشفتين وتيجان أسنان فعلية، لكنها أظهرت كتل دعم وجذور وعظام تحجب الهدف، وفحص F رصد تقاطعات. لذلك هذا اختيار **أساس للتحرير** وليس اجتياز بوابة تشريح الراحة.

الإطار المثبت للمشتق (متر، يميني):

```
x = 0.14 - source.x
y = source.z - 0.10
z = source.y
```

لا تغيير مقياس ولا دمج متبرعين. يجب تدقيق أصل الأسنان المحملة في demo وحدود دليل وحدة المتبرع؛ تحميلها معًا لا يثبت هوية المتبرع. تحفظ الأسطح الخام وبصماتها. قص تيجان الأسنان وفصل دعم الجذور تعديلات معلنة في المصدر القابل للتكرار. لا تُسمح الواجهة حتى صور الراحة المصححة وفحص التقاطعات وتوضيح الأنف/الحنك/البلعوم.
