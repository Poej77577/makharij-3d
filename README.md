# مخارج — فحص الأساس التشريحي

مشروع عربي RTL لتطوير تعليم مخارج الحروف. الحالة الحالية ودليل الاختبار في `docs/STATUS.md`؛ **ليس نموذجًا معتمدًا**. أولوية التسليم لصحة الهندسة قبل التوسع في الحروف.

مصدر Blender القابل للتعديل في `model/`، والمدخلات المرخصة محفوظة مع البصمات. إعادة البناء:

```sh
blender -b -t 2 --python scripts/build_model.py
```

Blender 4.3.2 أو أحدث. لا توجد خدمة مدفوعة أو مفتاح API مطلوب. يخرج البناء GLB وأدلة صور وفحص الحواف. المحاور النهائية: X خلفي، Y علوي، Z جانبي؛ الوحدات متر. شاهد `docs/PROVENANCE.md` قبل إعادة التوزيع.
