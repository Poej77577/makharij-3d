# مخارج — بناء تشريحي من الصفر

مشروع قيد التنفيذ وفق docs/REQUIREMENTS.ar.md ومرجع المستخدم docs/VISUAL-REFERENCE.ar.md. تتوفر هندسة Badin/ArtiSynth الفعلية ومصدر Blender وعارض تقني بعرضين وحركة راء أولية. ليست منصة تعليمية مكتملة أو معتمدة. اكتملت مهمة أجنت التشريح ويعمل المنسق حاليًا وحده لتقليل الاستهلاك.

## التشغيل

Node24/npm11 مختبران:

```sh
npm ci --no-audit --no-fund
npm run build
npm run preview -- --port 4173 --strictPort
```

للتطوير: `npm run dev`. الشيفرة تحمل GLB فعليًا؛ فشل التحميل لا يستبدل بنموذج بدائي. تطبيق React ليس شرطًا؛ العارض التقني الحالي TypeScript وThree.js، دون تعقيد واجهة إضافي.

## الأصول والتكرار

Blender4.3.2 مستخدم في الإعداد. من جذر المشروع:

```sh
python docs/assets/verify_selected_source.py
blender -b -t 4 --python scripts/anatomy/build_rest.py
```

المصدر الأصلي المختار وحقوقه وبصماته في assets/source/artiSynth (30 ملفًا). لا يعتمد البناء على checkout المرشحين المتجاهل. التعديلات قابلة للتكرار، والوحدات متر والمحاور X أمامي/Y علوي/Z جانبي. راجع docs/DECISIONS.ar.md وإسناد المصدر. تحميل أجزاء معًا لا يثبت وحدة المتبرع؛ تصحيح الملاءمة تقني غير مقاس.

أحدث دليل حركة الراء وخطوات الفحص في docs/validation/CONTINUATION-v10.ar.md؛ يحتفظ docs/validation/RA-PROTOTYPE-v6.ar.md بتاريخ الإصدارات السابقة. ملفا GLB/Blender للحركة في assets/anatomy/makharij-ra-prototype.*. تغيير هندسة الراحة يحتاج إعادة معايرة الحركة وفحص الملف المصدر مجددًا؛ لا تكسر فحص SHA لمجرد تجاوز خطأ.

## الحالة

نجحت فحوص الراحة المحدودة وتجربة راء طرفية تقنيًا، مع دليل من ملف GLB النهائي والمتصفح وفيديو دورة كاملة. لا تساوي هذه النتائج مراجعة علمية. القاف والميم وبقية الحركات غير جاهزة، والتفخيم والترقيق غير معايرين، والبطانة الأنفية والمحارات إعادة بناء مؤلفة غير مقاسة مستوحاة من مرجع المستخدم. النموذج الحالي لم يطابق المرجع بعد. لا صوت معتمد مرخص أو اعتماد مستقل أو نشر مثبت.

المتن التراثي رُبط بمقتطفات فعلية من الجزرية؛ لم نتحقق من منهاج الدارسين أو مطابقة المنهج الأردني. التفاصيل في docs/content. ليس عدم توفر تسجيل مرخص إذنًا باستخدام TTS أو إعادة توزيع تسجيل مجهول الحقوق.

## التسليم

`python scripts/package_source.py` يجهز حزمة المصدر خارج المستودع في /workspace/artifacts دون الأسرار والكاش والمرشحين. dist ناتج استضافة ثابتة للعارض التقني فقط؛ أدوات نشر Sites غير متاحة في الجلسة ولم يحدث نشر أو دفع GitHub مثبت.
